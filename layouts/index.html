記事が公開されるまで

  1. Markdownで書く

    記事は Markdown のファイル1つ。開発の話は tech、毎日の話は life のフォルダに置きます。

  2. Hugoで確かめる

    手元で hugo server を動かして、ブラウザで見た目を確かめてから公開します。

  3. GitHub Pagesで公開

    main ブランチに push すると、GitHub Pages の sunja-an.github.io に載ります。
